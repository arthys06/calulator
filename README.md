# Personal Expense Calculator

A simple, user-friendly web application designed to help individuals manage their personal finances effectively. This project tracks monthly income, monitors categorical expenditures, and automatically evaluates net savings in real-time.

## 📱 Application Preview
![Application Preview](screenshot.png)

## 🚀 Features
* **Income Management:** Define and modify total monthly income values.
* **Expense Tracking:** Capture expense details including description, cost, and classification.
* **Dynamic Calculations:** Automated real-time tracking of net savings balance.
* **Categorized Breakdowns:** Instant reporting of aggregated totals sorted by functional areas (e.g., Food, Rent, Utilities).

## 🛠️ Tech Stack
* **HTML5:** Semantic structural components.
* **CSS3:** Responsive layout design with modern visual cues.
* **JavaScript (ES6+):** Programmatic state management, conditional loops, arrays, and DOM manipulation.
